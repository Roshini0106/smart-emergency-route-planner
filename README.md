# 🚑 Smart Emergency Route Planner

A web-based emergency route planning system designed to help visualize ambulance routes to hospitals.

## 🚀 Features

- Interactive OpenStreetMap
- Search ambulance and hospital locations
- Automatic road route calculation
- Distance calculation
- Estimated travel time
- Emergency route visualization
- Ambulance movement animation
- Emergency route status
- Responsive dashboard interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap
- Nominatim
- OSRM Routing API
- GitHub Pages
